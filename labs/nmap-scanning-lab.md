# Nmap Scanning Lab

## Objective
Perform network reconnaissance and identify open ports and services within a simulated environment.

## Tools Used
- Nmap
- Kali Linux

## Commands Used
```bash
nmap -sV 192.168.1.1
```

## Findings
- Port 22 (SSH) open
- Port 80 (HTTP) open
- Apache web server detected

## Lessons Learned
This lab improved my understanding of network enumeration, service detection, and how attackers gather information during reconnaissance phases.
