# Network Security Capstone

## Overview
This project focused on simulating a small enterprise network environment to identify vulnerabilities, monitor suspicious activity, and improve overall network security posture.

The project involved vulnerability assessments, intrusion detection configuration, network traffic analysis, and risk remediation planning using industry-standard cybersecurity tools.

---

## Objectives
- Identify system vulnerabilities within a virtualized network environment
- Configure intrusion detection mechanisms
- Analyze network traffic and logs for anomalies
- Develop remediation strategies to reduce security risks

---

## Tools & Technologies
- Nessus
- OpenVAS
- Snort IDS
- Wireshark
- Nmap
- Kali Linux
- Windows Server

---

## Configuration
The environment was configured within a virtualized lab setup simulating a small enterprise network.

Security tasks included:
- Vulnerability scanning
- Intrusion detection rule configuration
- Network traffic monitoring
- Firewall and mitigation recommendations

---

## Key Responsibilities
- Conducted vulnerability scans using Nessus and OpenVAS
- Developed Snort intrusion detection rules
- Analyzed network traffic to identify suspicious activity
- Documented vulnerabilities and remediation strategies
- Produced a final risk analysis report
